# 🌌 Animated Profile Website

A sleek, futuristic profile website featuring a dark aesthetic, animated particles, glowing typography, interactive cursor effects, social links, and background music.

## ✨ Features

- 🌑 **Dark Theme** — Minimalist design with a dark background.
- ✨ **Animated Particles** — Floating particles with dynamic connecting lines.
- 🖱️ **Custom Cursor** — Custom mouse cursor with a smooth animated ring.
- 💡 **Glowing Typography** — Animated text with a subtle pulsing glow effect.
- 👤 **Profile Section** — Customizable avatar, name, tagline, and badges.
- 🔗 **Social Links** — Interactive cards for social media and external links.
- 🎵 **Background Music** — Optional looping background audio.
- 📱 **Responsive Design** — Adapts to different screen sizes.
- 🖥️ **Browser Information** — Collects selected technical information through browser APIs.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Canvas API
- WebGL API
- Browser Navigator API

## 🚀 Getting Started

No installation or build process is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/troubleithink/HTML-GRABBER/index.html.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR-REPOSITORY
   ```

3. Open `index.html` in your browser.

## ⚙️ Customization

Edit `index.html` to personalize the website.

- Replace `NAME` with your preferred display name.
- Replace `TEXT` with your own descriptions and profile information.
- Update the social links and URLs.
- Customize the location, music, games, and badges.
- Adjust the CSS to change colors, animations, and layout.
- Configure or remove the webhook integration as needed.

## 🔐 Privacy Notice

The current implementation collects certain technical information through browser APIs and external services.

Depending on browser support, this may include:

- Public IP address and approximate location
- Browser and operating system information
- Device type and screen resolution
- Language and time zone
- GPU, memory, and CPU information
- Battery and network information
- Referrer information

Some information may be unavailable depending on the browser and device.

Collected information is sent to the configured webhook. Make sure visitors are appropriately informed, obtain consent where required, and comply with applicable privacy laws before deploying the website publicly.

**Never publish private webhook URLs, credentials, or other secrets in a public repository.**

## 🌐 Browser Compatibility

The website is designed for modern browsers. Some features, including battery status, network information, GPU identification, and automatic audio playback, may be restricted or unsupported depending on the browser.

Background music may require user interaction before playback begins.
